## 📐 `docs/architecture` — how every project is wired

```mermaid
flowchart LR
    UI["🖥️ Presentation<br/>React · Blazor"] --> APP["⚙️ Application<br/>Use cases · DTOs · Validation"]
    APP --> DOM["💎 Domain<br/>Entities · Business rules"]
    INF["🗄️ Infrastructure<br/>SQL Server · External APIs"] --> APP
    INF -.-> DOM
```

<sub>Dependencies point inward → the domain never knows about the database or the UI.</sub>
